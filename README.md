## 2. 핵심 지표 정의

| 지표 | 산식 및 기준 |
|---|---|
| **총 수주액 합산** | 현재 필터 조건(기간 · 입찰범위 · 사업자 소재지 · 검색어)에 일치하는 1순위 낙찰금액 합산 (상단 배너 · 요약표 · 순위표 `<tfoot>` · 원장 배지 1원 단위 일치) |
| **평균 낙찰률 (1순위)** | 나라장터 공식 API `sucsfbidRate` (**1순위 낙찰금액 ÷ 예정가격 × 100**)의 산술평균 (`입찰참가수 ÷ 낙찰건수` 아님) |
| **낙찰률 `-` 미기재 사유** | 「협상에 의한 계약(제안서 평가)」 등 예정가격·낙찰률을 비공개 제공하는 공고는 G2B API가 빈값으로 반환하므로 `-`로 표기 (모달·원장에서 배정예산 대비 참고 비율 병기) |
| **동명이사 & 본·지사 규칙** | 동일 상호(`주식회사 렛츠`)라도 사업자번호와 대표자가 모두 다르면 별도 법인으로 분리하며, 동일 대표자 본·지사는 1개사로 통합(대구·경북 본사 주소 우선) |

## 3. 최신 데이터 업데이트 및 배포 방법

PC에서 아래 스크립트를 실행하면 노션(Read-Only) + 나라장터 최신 데이터를 재추출하고, 비밀키 노출 0건 검증 후 GitHub Pages에 자동 반영합니다.

```powershell
# 더블클릭 실행: sync_to_github.bat
# 또는 PowerShell 직접 실행:
python "ⓐ_261113_export_data.py" --deploy
```

- **5개년 심층 리포트 갱신**: `python "ⓐ_261113_fetch_history.py" <시작일> <종료일>` (과거 이력 보충) → `python "ⓐ_261113_dg_analysis.py"` (`dg_report.js` 재생성)
- **과거 연도(2020~2025)**: `python "ⓐ_261113_fetch_history.py" <시작일> <종료일>` → `python "ⓒ_261117_build_history.py"` (`history.js` 생성). 화면의 `📚 과거 연도 불러오기`를 누를 때만 내려받습니다.
- **전체 순위·기술/가격/종합 점수**: `python "ⓒ_261117_fetch_ranks.py"` (`ranks.js` 생성). 나라장터 순위 API가 하루 1,000건 한도라 `ⓒ_261117_daily_ranks.bat`으로 매일 이어받습니다.
- **행사 이력 · 심층분석 탭**: `extras.js`가 담당합니다. 심층분석의 API 키는 사용자의 브라우저에서 해당 AI 회사 서버로만 전송되며 저장소·서버에 남지 않습니다.
- **공개본과 로컬본 분리** (2026-11-16): 저장소에는 `data.js` · `dg_report.js`만 올립니다. `data.json` · `dg_report.json`은 로컬 분석용 전체본이며 `.gitignore` 대상입니다. 공개본에서는 노션 페이지 ID 등 내부 식별자를 뺍니다.
- **비기획 용역 제외**: 제목에 시설관리·조경·유지보수·실시설계·보험가입·채용대행 등이 들어간 공고는 기본 집계에서 제외합니다(화면의 `비기획 용역 제외` 체크로 끄고 켤 수 있고, `원본 표기 (v2 호환)` 모드에는 적용하지 않습니다).
- **보안 원칙**: `.env` 및 노션/나라장터 API 비밀키와 로컬 원본 캐시(`g2b_2026_cache.json`)는 `.gitignore` 및 사전 정규식 검증으로 공개 저장소에 절대 업로드되지 않습니다.
